## What happened, storefront side

1. Merged PR #2 (account-page black background) to `main`, rebuilt/redeployed
   the local dev container (`hw-hydrogen-storefront-node-docker`, port 5130
   — this is what `hoseworld.store` tunnels to), then discovered production
   (`www.hoseworld.co.za`) hadn't had a real release in a long time (stuck
   on `2026.07.202`) — released it for real for what was effectively the
   first time this session.
2. Wayne reported checkout completely broken on production immediately
   after — root-caused as pre-existing `.env.production` config gaps
   (empty `PUBLIC_PAYMENT_GATEWAY`, mismatched `INTERNAL_API_SECRET`) that
   had never been exercised by real production traffic before, not
   something the deploy itself broke. See companion file for full details.
3. Built two new features on `import-bulk-operations`, merged to `main`,
   released:
   - **Collection date/time validation** — new `app/lib/collectionSchedule.ts`
     (11 tests), enforced both client-side (min/max on the date/time inputs
     in `($locale).checkout.tsx`, inline error) and server-side (in
     `($locale).checkout.payment.tsx`'s action, so a direct POST can't
     bypass it). SAST-anchored, Mon–Fri only, ZA public holidays NOT
     accounted for (no holiday calendar exists in this codebase — flagged
     as a known gap, not fixed).
   - **Direct EFT payment option** — payment-method radio (PayFast vs EFT)
     in the review step, shown only when `EFT_ACCOUNT_NUMBER` is non-empty.
     EFT creates the same Draft Order as PayFast (via
     `($locale).checkout.payment.tsx` → `paymentMethod: 'eft'` in the
     payload to hw-storefront-ui's `/api/payment/initiate`) but skips the
     PayFast redirect; success page
     (`($locale).checkout_.success.tsx`) explains the order only proceeds
     once payment reflects, recaps the banking details + reference.
     **Banking details are empty on production on purpose** — see
     "Deferred to tomorrow" below.
4. Fixed the customer-facing courier label leaking TCG's real service-level
   name ("Local Overnight") — see companion file, fix lives in
   `hw-storefront-ui-node-docker`'s `api.shipping.rates.jsx`, but the
   *reason* it mattered is this repo's checkout renders `rate.title`
   verbatim (`($locale).checkout.tsx` line ~950) with no sanitization of
   its own — worth keeping in mind if any other consumer of that API is
   ever added here, it should not assume the title is pre-sanitized without
   checking.
